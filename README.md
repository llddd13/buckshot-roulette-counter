# 恶魔轮盘 · 记弹器

**中文** | [English](README.en.md)

手动标注弹匣，告诉你 **第几发是实弹、第几发是空弹**，还剩几发实弹几发空弹。
窗口**始终置顶**，浮在游戏画面之上。

![界面](docs/ui.png)

> 单个自包含 `exe`（约 33 KB），不需要装 Python / Node / 任何运行库，
> 只要 Windows 10/11 自带的 .NET Framework 4.8。

### 直接下载

**[⬇ 下载 BuckshotCounter.exe](https://github.com/llddd13/buckshot-roulette-counter/releases/latest/download/BuckshotCounter.exe)** —— 双击即用，不用装任何东西。

也可以从仓库根目录拿 `恶魔轮盘记弹器.exe`（同一个文件），或者用 [`build.ps1`](build.ps1) 自己编译。

## 2. 怎么用（三步）

### 第一步：装弹

每局开始时，游戏会告诉你这局装了几发实弹几发空弹。
用下面的 **实弹 [−] 3 [+]** 和 **空弹 [−] 2 [+]** 设成一样的数字，点 **【装弹】**。

下面就会排出对应数量的**灰色未知弹**：

```
[?][?][?][?][?]      ← 5 颗，全是未知
```

### 第二步：标注

| 操作 | 效果 |
|---|---|
| **左键**点一颗 | 标成**红色实弹** |
| **右键**点一颗 | 标成**蓝色空弹** |
| 再点一次同色 | 取消标注，变回灰色未知 |
| **点第 1 颗** | 视为**已击发** —— 标完直接删掉它，剩余数自动减 |

> 标记和击发都有 **1 秒防误触冷却**（弹匣会变暗提示），但【撤销】和【装弹】不受限制。详见下面。

### 第三步：跟着打

开一枪就点一下最前面那颗（左键=实弹、右键=空弹）。
击发时你必然看到打出来的是什么，所以这一下同时完成了"记录"和"消耗"。

用**放大镜**看了后面某颗，就直接左/右键给它上色（它不在第 1 位，所以只会标色、不会删）。

点错了按 **【撤销 ^3】**，可以一路退回。

### 未知弹下面的百分比

每颗**还没标注**的子弹下面会显示一个百分比 —— 它是**实弹的概率**。

算法：还剩 `剩余实弹` 发实弹，其中 `已标注实弹` 发已经标出来了，
剩下那些必然分散在 `还没标注` 个未知位置里，没有别的顺序信息时每个位置机会均等：

```
实弹概率 = (剩余实弹 − 已标注实弹) ÷ 还没标注
```

举例：

| 情况 | 计算 | 显示 |
|---|---|---|
| 装 3 实 2 空，一个都没标 | 3 ÷ 5 | 每颗都是 **60%** |
| 标出 1 颗是实弹 | (3−1) ÷ 4 | 每颗都是 **50%** |
| 标出 1 颗是空弹 | 3 ÷ 4 | 每颗都是 **75%** |
| 打掉 1 发实弹 | 2 ÷ 4 | 每颗都是 **50%** |

颜色也会跟着变：概率越高越偏红，越低越偏蓝。

### 防误触

**标记和击发有 1 秒冷却**：点完一下之后 1 秒内再点/再按热键都不会生效，
防止手抖双击或多标一发。冷却期间弹匣会**整体变暗**，一眼就能看出"现在点不动"，
底部也会提示还剩多久。

两个例外 —— 这两件事**不受冷却限制**，方便误触后马上补救：

- **【撤销】**：误触后立刻就能退回来
- **【装弹】/【重新装弹】**：换局时不用等

冷却时长可以点右上角 **【设】**，在设置栏里直接调（每档 100 毫秒），也可以写 `config.ini`：

```ini
ClickCooldownMs=1000     ; 改成 0 就是关闭冷却，改成 500 就是半秒
```

## 3. 为什么这样设计

- 装弹顺序**每局随机**，靠脑子记不住，所以需要工具替你记
- 但**子弹总数是游戏明说的**（"3 发实弹 2 发空弹"），所以起点很明确
- **击发的永远是最前面那颗**，而且你必然会看到它的类型 —— 所以"点第 1 颗 = 击发并删除"是最省事的
- 放大镜只告诉你**某一颗**的颜色，所以"就地标色"是另一种独立操作

不需要校准、不需要识别屏幕、不受分辨率/光照/视角影响，**100% 准确**。

## 4. 全局热键（游戏全屏时用）

游戏全屏时鼠标被游戏占用，点不到悬浮窗，所以关键操作都做了热键：

| 热键 | 作用 |
|---|---|
| `Ctrl + Alt + 1` | 第 1 发是**实弹**（击发并删除） |
| `Ctrl + Alt + 2` | 第 1 发是**空弹**（击发并删除） |
| `Ctrl + Alt + 3` | 撤销 |
| `Ctrl + Alt + 4` | 重新装弹（按当前设定） |
| `Ctrl + Alt + H` | 显示 / 隐藏悬浮窗 |
| `Ctrl + Alt + 6` | 开关鼠标穿透 |

> 按钮上没写热键，但热键一直是有效的；启动时状态栏也会提示一遍。

## 5. 界面说明

```
┌────────────────────────────────────────────────┐
│ 恶魔轮盘 · 记弹器            [📌] [🖱] [⚙] [×]│  📌=置顶 🖱=鼠标穿透 ⚙=设置 ×=关闭
├────────────────────────────────────────────────┤
│  剩余实弹 3  │  剩余空弹 2  │  还没标注 5       │
├────────────────────────────────────────────────┤
│  共 5 发                                        │  ← 第 1 发若已知则显示"第 1 发（下一发）→ 实弹"
├────────────────────────────────────────────────┤
│        [?][?][?][?][?]                          │  ← ▶ 标在最前面那颗上 = 下一发
│        60% 60% 60% 60% 60%                      │  ← 这一颗是实弹的概率
├────────────────────────────────────────────────┤
│  实弹 [−] 3 [+]  空弹 [−] 2 [+]  [装弹]        │
│  [撤销]           [重新装弹]                    │
├────────────────────────────────────────────────┤
│  状态行（只写上一步做了什么，平时是空的）        │
└────────────────────────────────────────────────┘
▼ 点【⚙】多出下面这块
┌────────────────────────────────────────────────┐
│  使用说明                                       │
│    左键标记为实弹，右键标记为虚弹               │
│    标记第一发视为标记并击发                     │
│  ──────────────────────────────────────────    │
│  防误触间隔   [−] 1000 毫秒 [+]                 │
│  窗口不透明度 [−] 95 %    [+]                   │
│  [窗口置顶：开] [鼠标穿透：关] [窗口归位]        │
└────────────────────────────────────────────────┘
```

> 顶部三个图标：**📌 图钉 = 置顶**（亮蓝色表示已开启）、**🖱 虚线窗+鼠标 = 鼠标穿透**、**⚙ 齿轮 = 设置**。

- **剩余实弹 / 剩余空弹**：按"装弹数 − 已击发数"实时算出来，就是你还剩多少发实弹、多少发空弹
- **还没标注**：弹匣里还有几颗颜色未知
- **▶ 标记**：永远在最前面那颗上，代表"下一发要打的就是它"
- **📌 置顶**：亮蓝色=已置顶。没浮在游戏上就点它
- **🖱 鼠标穿透**：开启后鼠标点击会穿过去给游戏，图标会亮起来
  - **穿透时这个图标依然点得到**：程序会在它上面盖一个独立小窗口，所以永远不会被锁死
- **⚙ 设置**：展开 / 收起设置栏（窗口会跟着变高变矮），操作说明就在它最上面
- **拖动窗口任意空白处**可移动，位置自动记住；跑偏了用【窗口归位】拉回右上角

### 设置栏里有什么

最上面是**使用说明**，下面才是各项设置：

| 项目 | 说明 |
|---|---|
| **防误触间隔** | 标记/击发的冷却，1000 毫秒起步，每档 100，可以调到 0 = 关闭 |
| **窗口不透明度** | 35% ~ 100%，每档 5%。调低了能透出游戏画面 |
| **窗口置顶** | 和顶部的📌是同一个开关 |
| **鼠标穿透** | 和顶部的🖱是同一个开关 |
| **窗口归位** | 一键把窗口挪回屏幕右上角 |

## 6. 常见情况

**打了一枪，但忘了点第 1 颗？**
点 **【撤销】** 回到之前，或者直接继续——剩余数会偏一发，下一枪补点一次就行。

**装弹数改了？**
调好 [−] [+] 再点【装弹】，弹匣会按新数字重置（这一步也可以撤销）。

**游戏里显示的是"虚弹/空包弹"？**
就是本工具里的**空弹（蓝色）**，同一个东西。

**一局打完了想开新局？**
改好数字点【装弹】即可，会清空重新排灰色未知弹。

## 7. 文件说明

| 文件 | 说明 |
|---|---|
| `恶魔轮盘记弹器.exe` | 主程序（独立运行，双击即用） |
| `config.ini` | 运行后自动生成：窗口位置、透明度、上次的装弹数 |
| `src\BuckshotCounter.cs` | 全部源码（界面、弹匣模型、热键、鼠标交互） |
| `src\RackDetector.cs` | **未接入程序**的自动识别实验模块（见下） |
| `tools\RackTest.cs` | 自动识别模块的回归测试 |
| `build.ps1` | 从源码重新编译出 exe |
| `run-tests.ps1` | 跑自动识别模块的回归测试 |

### 关于自动识别

早期版本尝试过"直接读屏幕上的子弹颜色"，单机桌面视角下用 13 张真实截图验证全部正确
（粉红=实弹、灰色=空弹），但：

- 多人模式里枪在转，子弹位置/角度每帧都变，固定区域抓不住
- 全屏自动找弹槽时，桌面上排列整齐的其它色块会被误判

所以**程序里没有启用它**，改成了上面这套手动标注 —— 更快、更准、不受任何画面因素影响。
`src\RackDetector.cs` 保留作为实验记录，没有编译进 exe。

在 150% 缩放的 2560×1600 屏幕上用真鼠标真键盘逐项跑过：

| 步骤 | 结果 |
|---|---|
| 装弹（3 实 + 2 空） | 排出 5 颗灰色未知弹，计数 3 / 2 / 5 ✓ |
| **右键**点第 3 颗 | 第 3 颗变蓝色"空"，还没标注 5 → 4 ✓ |
| **左键**点第 1 颗 | 剩余实弹 3 → 2，该颗被删除（视为击发），剩 4 颗 ✓ |
| `Ctrl+Alt+3` 撤销 | 完整回到上一步，蓝色标注也一起恢复 ✓ |
| `Ctrl+Alt+4` 重新装弹 | 弹匣按设定重置 ✓ |
| **快速连点第 1 颗两次** | **只生效一次**（剩余实弹只减 1），防误触有效 ✓ |
| **冷却中立刻按撤销** | 立即生效，不受 1 秒限制 ✓ |
| 等冷却结束再点 | 恢复正常 ✓ |
| 概率显示 | 装 3 实 2 空 → 每颗未知弹下面标 **60%** ✓ |
